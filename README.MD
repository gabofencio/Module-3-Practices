# 😼 Proyecto final Módulo 2 - Seguimiento de Libros (Comment Box) 😼

Repositorio de proyecto final Del modulo 3.

El proyecto fue desarrollado maquetando con `HTML` y estilizando con `CSS` además del uso de `JavaScript` para la funcionalidad. Para el control de versiones se usó `Git` y para el alojamiento del repositorio y el despliegue de la página se usaron `GitHub` y `GitHub Pages`, respectivamente. 

>nota: El repositorio cuenta con las diversas prácticas de plataforma y clase del modulo además del proyecto final.

-----------------------------------------------------------------------------

## 😼 Propósito 😼

Este proyecto se llevo a cabo para desarrollar y fortalecer habilidades y conocimientos de desarrollo web haciendo uso de HTML, CSS, JavaScript, Git, GitHub y GitHub Pages.

-----------------------------------------------------------------------------
## 😼 Clonar el repositorio 😼

1️⃣ Ejecuta el siguiente comando:

``` bash
git https://github.com/gabofencio/Module-3-Practices.git
```

2️⃣ Accede a la carpeta del proyecto:

``` bash
cd Module-3-Practices
```

-----------------------------------------------------------------------------
## 😼 Acceder a proyecto desde Visual Studio Code 😼

1️⃣ abre Visual Studio Code. 

2️⃣ Selecciona la pestaña de *File → Open Folder...* ó usa el atajo de teclas (*Ctrl + K   Ctrl + O*).

3️⃣ Selecciona la carpeta del proyecto.

>Puedes abrirlo igualmente desde la terminal con el comando:
``` bash
code .
```
-----------------------------------------------------------------------------
## 😼 Instala Live Server en Visual Studio Code 😼

1️⃣ Ve a la sección de extensiones (*ctrl + shift + X*)

2️⃣ Busca *Live server*

3️⃣ Instala la extensión desarrollada por *Ritwick Dey* 

-----------------------------------------------------------------------------
## 😼 Cómo ver el sitio 😼

1️⃣ Accede al archivo *index.html*

2️⃣ Haz click derecho sobre el mismo

3️⃣ Selecciona la opción de **open with live server (Alt + L  Alt + O)**  ó selecciona la opcion de **Go Live** que se encuentra en la esquina inferior a la derecha de la interfaz 

>Se abrirá automaticamente la página en tu navegador predeterminado.
